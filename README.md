# HELLDIVER DGLAB

通过《绝地潜兵 2》的游戏画面读取自己的血量，再生成 DG-LAB 反馈。不读游戏内存，不注入游戏。

提供两种 Windows x64 公开测试包：**官方后端独立版 v1.0.0 Beta 3** 和 **DGHub 1.0.7 插件**。两版都有可调 HUD、五类反馈、独立 A/B 强度、可调残血门槛、三种死亡模式、F8、灵动岛和截图检查。

## 这次更新了什么

在原有 1080p 可调 HUD 的基础上，增加三种死亡反馈模式、DGHub 极简直播按钮，以及 **2560×1440／3840×2160 实验性推算适配**。三种分辨率各有 HUD 0.75–1.25、每档 0.05、共 11 档。

| 实际抓屏尺寸 | 支持说明 |
|---|---|
| 1920×1080 | 沿用既有配置；七档有满血实拍定位依据，四档为插值 |
| 2560×1440 | 从对应 1080p 配置按 4/3 推算；实验性，未实机验收 |
| 3840×2160 | 从对应 1080p 配置按 2 倍推算；实验性，未实机验收 |

高分辨率实时识别须先选定 HUD 档位，并主动开启“允许实验性 2K／4K 适配”；默认关闭。程序读取所选屏幕的实际抓屏像素尺寸，不自动改显示设置、不缩小整张游戏画面、不猜 HUD 档位。截图检查可直接预览支持尺寸的原图，不连接设备。

2K／4K 基于 1080p 等比推算，**未完成真实高分辨率游戏、抓屏及设备验收**；合成图、原图重采样和软件协议通过不等于实机通过。仅覆盖上述完整铺满屏幕的 16:9 尺寸，超宽屏、窗口留边和 HDR 不在本轮范围。配置、使用及回退见 [多分辨率测试指南](docs/resolution_testing_20261017.md) 和 [本轮验收记录](docs/resolution_acceptance_20261017.md)。

死亡模式与直播按钮的详细操作见 [模式测试与回退](docs/death_live_testing_20261014.md)；该文保留 Beta 2／1.0.6 的历史版本名称，相关功能在当前版本继续保留。

## DGHub 插件怎么用

1. 停用旧插件并备份完整旧包和对应宿主配置，下载上表的 **DGHub 1.0.7 完整插件 ZIP**，在 DGHub 插件中心导入。同 ID 更新会替换旧插件；不要只复制 EXE，也不要直接双击插件 EXE。
2. 游戏完整铺满所选屏幕，建议无边框全屏。在插件配置中选择正确的显示器编号和与游戏相同的 HUD 档位。实际抓屏为 2560×1440／3840×2160 时，主动开启“允许实验性 2K／4K 适配”；1080p 不需要开启。
3. 设置仅 A、仅 B 或 A+B，以及五类反馈的波形、强度和各通道上限。将本插件的待机强度设为 **0**，保持“允许输出”保险打开。
4. 启用插件，等待启动检查就绪。每次启用默认暂停；在地面战场按 **F8**，或点击浮窗／灵动岛按钮开始，再次操作暂停。停用插件或关闭控制面板结束会话。
5. 暂停后点击 **CHECK** 检查本地原始截图，点击 **GUIDE** 查看完整指南。没有设备时可以识别血量，显示 `VISION ONLY`，A/B 请求为 0；实际反馈需先在 DGHub 中连接 APP 和设备。

“允许输出”是保险开关，重新打开后仍需 F8／浮窗启动。HUD、实验开关、波形、强度、通道、残血门槛、死亡模式和面板模式的修改在**停用后重新启用**生效，F8 暂停／恢复保持当前会话配置。设备接入或断开也会暂停，重新确认后才能输出。F8 被占用时显示 `F8 UNAVAILABLE`，可使用完整浮窗按钮。

DGHub 插件使用原有控制窗／灵动岛，遥遥领先风格主界面属于独立版。直播模式只精简本插件窗口，不接入弹幕或礼物，也不隐藏宿主和事件卡片。基础流程见 [插件指南](docs/dghub_plugin_guide.md)，新版设置和回退以 [多分辨率指南](docs/resolution_testing_20261017.md) 为准。

## 独立版怎么用

完整解压独立版 ZIP，双击 `HELLDIVER_Main.exe`，保留同目录的 `_internal`。

![独立版主窗口](docs/images/main-window.png)

1. 先关闭旧版本，完整解压新包。不要同时运行多个输出版本。
2. 游戏完整铺满选中的屏幕，建议无边框全屏。首轮建议在已有实拍定位依据的 1920×1080 下测试。
3. 在软件 **HUD 设置**中选择游戏相同的 HUD 大小。实际抓屏为 2560×1440／3840×2160 时，主动开启“允许实验性 2K／4K 适配”，再保存。
4. 可先用 **截图检查**读取原始截图，无需连接 APP；或点 **仅测试识别**，在游戏里测试实时血量。
5. 要连接时，选择与手机同一局域网的电脑地址，点击 **连接 APP**，在官方 DG-LAB APP 的 SOCKET 入口扫描新二维码。
6. 进入地面战场后按 **F8** 开始，再按 F8 暂停。结束时点击 **停止全部**。

初始状态是暂停，不会自动开启反馈。F8 暂停保留本次配对，但不解锁设置；停止全部后才能改设置，保存的设置在下次会话生效。

基础流程见 [独立版指南](docs/main_official_guide.md)，新版分辨率设置、测试顺序和回退见 [多分辨率指南](docs/resolution_testing_20261017.md)。

## 有哪些反馈

| 反馈 | 触发规则 | 独立版默认波形 | DGHub 默认波形 | 默认 A／B 基准 |
|---|---|---|---|---|
| 受伤 | 0.2 秒内累计掉血，强度随伤害量变化 | 连击 | 连击 | 20／20 |
| 残血／濒死 | 有效血量大于 0 且低于所选门槛，持续反馈 | 呼吸 | 呼吸 | 10／10 |
| 治疗确认 | 检测到有效回血 | 潮汐 | 潮汐 | 15／15 |
| 治疗持续舒缓 | 回血期间持续，最近一次回血后默认继续 2 秒 | 原治疗模板 | 心跳节奏 | 5／5 |
| 死亡 | 连续有效血量从正数到零；按所选死亡模式结束，默认定时 5 秒 | 原死亡模板 | CS2-死亡 | 40／40 |

- 残血门槛可设 **0–100% 的整数**，默认 75%。等于门槛不触发；0% 仅关闭残血层，不关闭受伤、治疗或死亡；100% 在满血时不触发。
- 受伤／治疗确认默认持续 2 秒，定时死亡默认持续 5 秒。波形优先级为死亡 ＞ 治疗确认 ＞ 受伤 ＞ 治疗舒缓 ＞ 残血。某事件在两路均无强度贡献时不抢占波形。
- 支持仅 A、仅 B、A+B；双路共用波形和节奏，强度及总上限分别计算。默认仅 A。
- 独立版内置 18 个波形选项，含官方 16 组 V3 示例和原治疗／死亡模板；DGHub 插件从宿主波形库选择，启动时校验所选预设，按完整周期播放。
- 无有效 HUD、失帧、暂停、断线或退出会停止反馈并清空识别基线，不把识别失败当成死亡。

软件界面的 A/B 是**软件输出／插件请求**，APP 的上限、实际显示和体感不一定与设置值相同。独立版主窗口状态超过一秒未更新时显示未知。DGHub 多插件在每通道取最大强度层，停用本插件不代表其他插件也停止。

DGHub 版的短时强度请求会产生宿主事件卡片，可能触发高强度音效。暂停／停止申请本插件层归零并停止续发；SDK v1 没有设备波形缓存清空确认。具体说明见 [插件指南](docs/dghub_plugin_guide.md#强度与故障排查)。

### 三种死亡模式

| 模式 | 何时结束死亡层 |
|---|---|
| 定时反馈（默认） | 默认 5 秒及原有退出规则 |
| 持续至复活 | 重新确认有效正血量 |
| 一次也不能死 | 手动 F8 重置，或结束整个会话；复活不解除 |

三种模式都需要先确认有效正血量，再确认零血；首次识别就是零、HUD 消失或基线重建不能凭空触发死亡。没有新增观战、增援动画或结算识别。

挑战触发后，**第一次 F8 清除标记、全部反馈和基线，并保持暂停；第二次 F8 才开始**。鼠标暂停和保险关闭不清除挑战，恢复后可能继续死亡反馈。无 HUD 时两路停止，但保留已确认的持续死亡标记；恢复首帧只重建基线。失帧、抓屏异常、断线和发送失败会锁停，不自动恢复。停止全部、停用插件或退出结束会话并清除标记。

“一次也不能死”触发后，复活后的受伤、治疗和残血仍按原规则叠加强度并限幅，死亡波形保持最高优先级。持续反馈依赖新有效帧，不是脱离画面的无限定时输出。

## HUD、截图检查和灵动岛

HUD 提供 **0.75–1.25，每档 +0.05，共 11 档**，不允许输入任意值。这里是游戏 HUD 大小，不是分辨率或 Windows 缩放。

- 1080p 的 0.75、0.80、0.85、0.90、0.95、1.00、1.25：已有满血实拍支持定位。
- 1080p 的 1.05、1.10、1.15、1.20：插值推算，有合成几何回归，尚未补齐实拍。
- 1440p／4K 的全部档位均为推算，不能沿用 1080p 的实拍标识；实时使用需先选定 HUD 档位并开启实验开关。
- 选错档、尺寸不符、遮挡或定位歧义会拒识，显示 `NO HUD / HP --`。不会自动换档或偷偷缩放原图。
- 独立版旧安装没保存新 HUD 设置时保留旧兼容预设；DGHub 版默认选择 1.00，使用前请与游戏设置核对。

会话期间分辨率固定。尺寸变化会停止并锁停，结束会话后重新开始；程序不自动切换配置，也不改游戏或 Windows 显示设置。

截图检查显示原图尺寸、放大的血条、端帽与测量框、原始血量及拒识原因。**单张图片只能测定位和单帧血量，不代表事件或设备反馈通过。**

![截图检查](docs/images/screenshot-check.png)

控制窗的 `ISLAND [-]` 可折叠成顶部灵动岛，折叠／展开不重新连接、不改变启停状态。悬停不展开或启动，窗口使用不激活置顶处理。游戏独占全屏下不保证可见，实际焦点表现需按游戏环境检查。

![灵动岛](docs/images/island.png)

DGHub 的控制面板还可选“直播模式（极简按钮）”：收起后仅有 32×32 逻辑像素的小按钮，随 Windows DPI 调整。单击只展开完整面板，拖动不启动识别；展开后可收回。此模式不隐藏 DGHub 自身窗口或其他插件，也不保证按钮不会被直播软件捕获。独立版不增加该按钮。

主窗口采用深蓝黑、青蓝、冷白、电路花纹和少量电弧。待机动画可关闭；会话启动后（包括 F8 暂停）停止动画，设置页、控制窗和灵动岛始终静态。

## 系统条件、依赖和连接权限

- 两种软件包均为 **Windows x64**；本机 Windows 11 已验证。其他系统没有本轮成品。
- Python、图像库、抓屏及主要 C++ 运行库随包；独立版另带 Node，DGHub 版另需宿主，本轮原生验证的是 1.9.7／SDK v1。软件仍使用 Windows 自带组件，Windows N／删减版缺少媒体组件时可能需要 [Media Feature Pack](https://support.microsoft.com/en-us/windows/media-feature-pack-for-windows-10-11-n-february-2023-2aaf89b8-f9d3-4322-98d0-612c9bea9c01)。没有完成所有干净系统的兼容验收；“运行库随包”不等于完全不依赖系统环境。
- 新 HUD 模式覆盖完整 **1920×1080**，并提供默认关闭的 **2560×1440／3840×2160 实验性推算**。仅支持完整铺满所选屏幕的现有 16:9 布局；其他尺寸、超宽屏、窗口留边和 HDR 不在支持声明内。
- 截图检查不需要 APP 或设备。独立版连接官方 APP 时，手机与电脑需在同一可信局域网；DGHub 版由宿主负责配对和设备连接，插件随包依赖完整，投稿“依赖资源”可留空。
- 独立版**平时不用管理员运行**。需要放行时，停止全部 → 连接权限 → 一键配置连接权限，阅读范围并明确确认后才请求管理员授权；可取消或撤销。
- 权限仅针对本包 `_internal/runtime/node.exe`，专用网络、本地子网 TCP 入站。不关闭防火墙、不开放公用网络、不做公网映射。指南显示实际后端路径。

连接失败不一定是权限问题，也可能是网卡选择、访客隔离或网络策略。移动软件目录会改变后端路径，旧放行规则不一定继续适用。

## 测试范围和已知限制

- **源码与软件协议**：2026-10-18 追加复测中，Python 全量回归 **2353 项通过**，官方后端 **16 项通过**；独立版最终程序 9 项检查、DGHub 22 个完整协议场景及对应最终程序检查通过。既有两段视频以独立进程和硬超时复测，结束输出归零。
- **图像来源**：33 组几何配置、合成血条及 1080p 原图重采样派生图完成自动检查。重采样不是高分辨率实拍；合成处理耗时不是实际 4K 游戏抓屏帧率。
- **原生宿主**：保留隔离 DGHub 1.9.7／SDK v1 的导入、配置和生命周期记录；软件模拟宿主不能代替其他宿主版本的验收。
- **作者手动测试**：2026-10-20，作者反馈 DGHub 1.0.7 与独立版 Beta 3 本机测试无问题。没有提供全部分辨率、手机和实体设备的测试明细，不将此结果扩展为所有环境通过。
- **仍未完成**：真实 1440p／4K HUD 布局、抓屏性能和对应游戏／手机／设备验收；四个插值档实拍、全部 Windows DPI／多显示器环境、干净系统和长时间使用的完整覆盖。
- **旧版问题不冒认修复**：已有 1.0.5 上线后很快下线的用户反馈，受影响环境的根因尚未确定。新版通过本机测试，不等于所有类似故障已解决。此前原生异常未在追加复测中重现，也不等于根因已定位。

## 源码与构建

普通用户只需下载完整软件包。开发者参见 [独立版构建](docs/build_main.md) 和 [DGHub 插件构建](docs/build_dghub.md)。主要目录：

```text
src/                  识别、反馈、连接与独立版界面
tools/desktop_app.py  独立版入口
main_desktop.spec     Windows 软件包构建配置
packaging/backend/   随包后端依赖清单
official_v2/         官方 SOCKET 后端适配
tests/                自动回归
docs/                 使用、验收和来源说明
dghub_plugin/         DGHub SDK 会话、输出、控制窗和配置生成
tools/dghub_live_entry.py  当前 DGHub 插件入口
dghub_live.spec       DGHub 完整运行包构建配置
```

当前 DGHub 清单由 `dghub_plugin/sdk_config.py` 生成。目录中的旧离线 `manifest.json` 和早期预览说明用于历史开发记录；可导入的 1.0.7 清单位于完整 Release ZIP 根目录。
