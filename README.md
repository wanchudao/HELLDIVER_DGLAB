# HELLDIVER DGLAB

通过《绝地潜兵 2》的游戏画面读取自己的血量，再生成 DG-LAB 反馈。不读游戏内存，不注入游戏。

**本次发布：官方后端独立版，Windows x64，遥遥领先风格 UI。不是 DGHub 插件。**

[下载完整软件包](https://github.com/wanchudao/HELLDIVER_DGLAB/releases/download/main-v1.0.0-beta.1/HELLDIVER_Main_Windows_x64_main-v1.0.0-beta.1.zip) · [发布说明](https://github.com/wanchudao/HELLDIVER_DGLAB/releases/tag/main-v1.0.0-beta.1) · [使用指南](docs/main_official_guide.md) · [升级与回退](docs/main_ui_upgrade_20261010.md)

请下载上面的完整软件包，**不要把 GitHub 自动生成的 Source code ZIP 当成可运行软件**。运行库随包，无需另装 Python、Node 或 DGHub；完整解压后双击 `HELLDIVER_Main.exe`，保留同目录的 `_internal`。

![独立版主窗口](docs/images/main-window.png)

## 怎么用

1. 先关闭旧版本，完整解压新包。不要同时运行多个输出版本。
2. 游戏使用 **1920×1080**，完整铺满选中的屏幕，建议无边框全屏。
3. 在软件 **HUD 设置**中选择游戏相同的 HUD 大小，保存。
4. 可先用 **截图检查**读取原始截图，无需连接 APP；或点 **仅测试识别**，在游戏里测试实时血量。
5. 要连接时，选择与手机同一局域网的电脑地址，点击 **连接 APP**，在官方 DG-LAB APP 的 SOCKET 入口扫描新二维码。
6. 进入地面战场后按 **F8** 开始，再按 F8 暂停。结束时点击 **停止全部**。

初始状态是暂停，不会自动开启反馈。F8 暂停保留本次配对，但不解锁设置；停止全部后才能改设置，保存的设置在下次会话生效。

## 有哪些反馈

| 反馈 | 触发规则 | 默认波形 | 默认 A／B 强度 |
|---|---|---|---|
| 受伤 | 0.2 秒内累计掉血，强度随伤害量变化 | 连击 | 20／20，作为基准 |
| 残血／濒死 | 有效血量大于 0 且低于所选门槛，持续反馈 | 呼吸 | 10／10 |
| 治疗确认 | 检测到有效回血 | 潮汐 | 15／15 |
| 治疗持续舒缓 | 回血期间持续，最近一次回血后默认继续 2 秒 | 原治疗模板 | 5／5 |
| 死亡 | 连续有效血量从正数到零，每条生命只触发一次 | 原死亡模板 | 40／40 |

- 残血门槛可设 **0–100% 的整数**，默认 75%。等于门槛不触发；0% 仅关闭残血层，不关闭受伤、治疗或死亡；100% 在满血时不触发。
- 受伤／治疗确认默认持续 2 秒，死亡默认持续 5 秒。波形优先级为死亡 ＞ 治疗确认 ＞ 受伤 ＞ 治疗舒缓 ＞ 残血。
- 支持仅 A、仅 B、A+B；双路共用波形和节奏，强度及总上限分别计算。默认仅 A。
- 内置 18 个波形选项，含官方 16 组 V3 示例和原治疗／死亡模板，运行时不联网下载。
- 无有效 HUD、失帧、暂停、断线或退出会停止反馈并清空识别基线，不把识别失败当成死亡。

软件界面的 A/B 是**软件输出**，不是 APP 或实体设备读回值；APP 的上限、实际显示和体感不一定与设置值相同。状态超过一秒未更新时显示未知，不用陈旧数值冒充实时状态。

## HUD、截图检查和灵动岛

HUD 提供 **0.75–1.25，每档 +0.05，共 11 档**，不允许输入任意值。这里是游戏 HUD 大小，不是分辨率或 Windows 缩放。

- 0.75、0.80、0.85、0.90、0.95、1.00、1.25：已有满血实拍支持定位。
- 1.05、1.10、1.15、1.20：插值推算，有合成几何回归，尚未补齐实拍。
- 选错档、尺寸不符、遮挡或定位歧义会拒识，显示 `NO HUD / HP --`。不会自动换档或偷偷缩放原图。
- 旧安装没保存新 HUD 设置时保留旧兼容预设，不擅自当作 1.00。

截图检查显示原图尺寸、放大的血条、端帽与测量框、原始血量及拒识原因。**单张图片只能测定位和单帧血量，不代表事件或设备反馈通过。**

![截图检查](docs/images/screenshot-check.png)

控制窗的 `ISLAND [-]` 可折叠成顶部灵动岛，折叠／展开不重新连接、不改变启停状态。悬停不展开或启动，窗口使用不激活置顶处理。游戏独占全屏下不保证可见，实际焦点表现需按游戏环境检查。

![灵动岛](docs/images/island.png)

主窗口采用深蓝黑、青蓝、冷白、电路花纹和少量电弧。待机动画可关闭；会话启动后（包括 F8 暂停）停止动画，设置页、控制窗和灵动岛始终静态。

## 系统条件与连接权限

- 本次软件包为 **Windows x64**；本机 Windows 11 已验证。不支持 macOS／Linux。
- Python、Node、图像库及主要 C++ 运行库随包；仍依赖 Windows 自带组件。Windows N／删减版缺少媒体组件时，可能需要 [Media Feature Pack](https://support.microsoft.com/en-us/windows/media-feature-pack-for-windows-10-11-n-february-2023-2aaf89b8-f9d3-4322-98d0-612c9bea9c01)。没有完成所有干净系统的兼容验收。
- 新 HUD 模式仅支持完整 **1920×1080** 的现有布局；其他分辨率、HUD 布局和窗口留边不在本次新增适配范围内。
- 截图检查不需要 APP、设备或后端。连接官方 APP 时，手机与电脑需在同一可信局域网。
- **平时不用管理员运行。** 需要放行时，停止全部 → 连接权限 → 一键配置连接权限，阅读范围并明确确认后才请求管理员授权；可取消或撤销。
- 权限仅针对本包 `_internal/runtime/node.exe`，专用网络、本地子网 TCP 入站。不关闭防火墙、不开放公用网络、不做公网映射。指南显示实际后端路径。

连接失败不一定是权限问题，也可能是网卡选择、访客隔离或网络策略。移动软件目录会改变后端路径，旧放行规则不一定继续适用。
