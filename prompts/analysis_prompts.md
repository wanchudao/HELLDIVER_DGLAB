# Helldivers 2 截图分析 Prompt 模板

## 使用说明

1. 复制下方任意一个 Prompt
2. 在 ChatGPT (chatgpt.com) 新建对话
3. 粘贴 Prompt，然后上传对应截图
4. 把 ChatGPT 的文字回复贴回给 AI 助手

---

## Prompt 1：受伤/血量分析

```
你是 Helldivers 2 (绝地潜兵2) 游戏画面分析专家。请分析这张截图中的玩家血条状态。

请按以下结构输出分析结果：

## 1. 血条位置
- 血条在画面中的大致区域（例如：左下角 / 中央偏下）
- 血条的像素坐标范围（如果可见）：从 (x1, y1) 到 (x2, y2)

## 2. 血条结构
- 血条是连续长条还是分段块状？
- 如果是分段：大约多少段？每段宽度大约多少像素？段间距多少？
- 血条总宽度大约多少像素？

## 3. 当前血量状态
- 从截图估计当前血量百分比（0-100%）
- 血条中可见的颜色段分别是什么颜色（用 RGB 近似值描述）
- 哪些段是"满血"（亮红色）？哪些段是"已消耗"（暗红/灰色）？
- 是否有"刚受伤"的痕迹（例如琥珀色/橙色的过渡段）？

## 4. 消耗方向
- 血条是从左往右消耗，还是从右往左消耗？
- 判断依据是什么？

## 5. 其他 UI 元素
- 血条上方或附近是否有体力条（绿色）？
- 是否有其他状态图标（护盾、buff、debuff）？
- 是否有受伤红屏滤镜？

## 6. 画面其他信息
- 画面整体明暗程度
- 是否有全屏特效（模糊、色差、暗角）
- 是否能判断当前是否在战斗中？

请尽量给出精确的像素坐标和 RGB 值。如果血条不可见，请说明原因（被遮挡、HUD 隐藏、死亡滤镜等）。
```

## Prompt 2：死亡画面分析

```
你是 Helldivers 2 (绝地潜兵2) 游戏画面分析专家。请分析这张截图是否为死亡/阵亡画面。

请按以下结构输出分析结果：

## 1. 死亡判定
- 这是死亡画面吗？请给出置信度（0-100%）
- 判断依据是什么？

## 2. 画面特效
- 是否有全屏红色滤镜？如果有，红色浓度如何（淡/中/浓）？
- 是否有模糊效果？
- 是否有色差/暗角？
- 画面主色调是什么（用 RGB 近似值描述）？

## 3. 血条状态
- 血条是否可见？
- 如果不可见，是被滤镜遮挡还是 HUD 消失了？
- 如果可见，血量是多少？

## 4. 死亡 UI
- 是否有"阵亡"、"DEAD"、"等待增援"等文字？
- 是否有骷髅图标或其他死亡标志？
- 是否有倒计时？

## 5. 画面其他信息
- 画面整体明暗程度
- 是否有其他 UI 元素（小地图、任务信息等）？
- 是否能判断死亡原因（画面中的敌人/爆炸等）？

请尽量给出精确的像素坐标和 RGB 值。
```

## Prompt 3：治疗/回血分析

```
你是 Helldivers 2 (绝地潜兵2) 游戏画面分析专家。请分析这张截图中是否有治疗/回血行为发生。

请按以下结构输出分析结果：

## 1. 治疗判定
- 这是治疗画面吗？请给出置信度（0-100%）
- 判断依据是什么？

## 2. 治疗特效
- 是否有治疗针/注射器的动画或图标？
- 是否有绿色/金色/青色的特效？
- 血条是否有"回血"动画（例如绿色波浪从左到右填充）？
- 是否有特殊音效提示（如果截图有波形/频谱的话）？

## 3. 血条状态
- 血条是否可见？
- 当前血量百分比估计（0-100%）
- 血条中是否有"正在恢复"的段（颜色不同于正常满血段）？
- 回血方向是从左到右还是从右到左？

## 4. 治疗来源
- 是否能判断治疗来源（自己使用治疗针 / 队友治疗 / 补给包 / 自然回血）？
- 是否有相关 UI 提示？

## 5. 画面其他信息
- 画面整体明暗程度
- 是否有其他 UI 元素（治疗针数量、技能冷却等）？
- 是否在战斗中？

请尽量给出精确的像素坐标和 RGB 值。
```

## Prompt 4：通用血条定位（用于满血/未知状态）

```
你是 Helldivers 2 (绝地潜兵2) 游戏画面分析专家。请在这张截图中定位玩家血条。

请按以下结构输出分析结果：

## 1. 血条可见性
- 血条是否可见？
- 如果不可见，原因是什么（HUD 隐藏、画面太亮/太暗、被遮挡）？

## 2. 血条位置
- 血条在画面中的区域
- 像素坐标范围：从 (x1, y1) 到 (x2, y2)
- 血条总宽度和高度（像素）

## 3. 血条结构
- 连续长条还是分段块状？
- 如果是分段：段数、每段宽度、段间距
- 血条颜色（用 RGB 近似值描述）

## 4. 当前血量
- 估计当前血量百分比
- 是否有空血段？如果有，大约多少段是空的？

## 5. 相邻 UI
- 血条上方是否有体力条？如果有，它的颜色和位置？
- 血条和体力条之间是否有分隔线？
- 血条左侧或右侧是否有数字显示（血量数值/护盾数值）？

请尽量给出精确的像素坐标和 RGB 值。
```
