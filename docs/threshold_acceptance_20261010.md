# 自定义残血／濒死门槛：两版验收与交付记录

日期：2026-10-10。独立主版采用官方 Node 后端；DGHub 为 1.0.5、SDK v1、DGHub 1.9.6 Windows x64。两个完整包分别构建，不覆盖当前安装，不修改防火墙或宿主全局设置，不使用重置卡。

## 实际交付功能

- 两版共用有效原始血量触发器：整数门槛 0–100，步长 1，缺字段默认 75。非零门槛严格使用 `0 < HP < N/100`，等于门槛不触发；100% 在满血时不触发。
- 0% 仅关闭残血持续层；受伤、治疗确认、治疗舒缓、死亡保持原规则，A/B 波形、强度和独立上限不被清空。回血退出残血层不停止治疗层。
- 独立版“反馈设置”增加百分比输入，停止全部后可修改；F8 暂停仍只读。保存进 EXE 旁 `feedback_settings.ini` 的独立 `[trigger]`，新会话写比例阈值。旧 sender 接口不变，单独更新强度保留已存门槛。
- DGHub 在“残血／濒死”区增加 number 字段，插件 ID 不变。宿主保存值在运行中标记待生效，F8 暂停／恢复不应用它；停用再启用才应用。SDK 状态和会话快照记实际应用值。
- 不改识别、75–125 HUD 几何档、反馈优先级、周期续播、短租约或连接协议。独立版继续不依赖 DGHub；插件不带官方 Node 后端。

## 证据限制与排除项

HUD 0.75、0.80、0.85、0.90、0.95、1.00、1.25 为满血实拍；1.05、1.10、1.15、1.20 仍是插值推算并以合成几何检查验证。仅适用完整 1920×1080 的现有布局，不新增分辨率支持。

本轮没有真实游戏、手机 APP 或实体设备验收，也没有干净 Windows 虚拟机测试。两版已有所有运行库，但软件自动测试不能保证所有机器、驱动或设备上的行为。

DGHub 归零指停止本插件续发、申请本插件强度层归零及宿主短时回退，不是设备波形缓存清空确认；0.30 秒租约不是设备端绝对停止上界。SDK 续发卡片和潜在音效行为不变，不自动关闭宿主全局设置。

开发中曾发现测试夹具本身的只读按钮未重启、短平台被既有伤害优先级遮盖、HUD 清基线标记期望错误，以及原生探针调用签名错误。均在测试工具修正后重跑完成；早期失败报告保留，不计为通过。没有为迎合测试放宽识别、改变优先级或绕过正常入口。

## 升级、回退与用户操作

两个新包为独立目录测试包，不自动安装或覆盖。可先使用新目录启动独立版／由用户导入 DGHub ZIP；不要同时运行两个版本或两种输出路线。

独立版：先停止全部、关闭程序并备份整个旧安装目录。保持原位置完整更新 EXE 与 `_internal`，保留 `feedback_settings.ini`、`hud_settings.ini`、`sessions`，不要只换 EXE。回退旧版时同时恢复升级前 `feedback_settings.ini`：不支持新功能的旧版会拒绝新增 `[trigger]`。

DGHub：先停用，备份旧完整 ZIP、安装目录、宿主 `config.json` 及外置会话目录，再导入 1.0.5。回退 1.0.4 必须同时恢复升级前该插件配置，旧版拒绝新字段，不能只换 EXE。恢复整份宿主配置前先关闭 DGHub，并确认它不会覆盖升级后其他插件的修改；若有其他修改，只恢复旧插件配置条目。会话不删除。

工作区 `backups/threshold_20261010` 保留旧完整主版 ZIP、旧 DGHub 1.0.4 ZIP 和本轮升级前宿主配置副本；它包含私人设置，不放入交付 ZIP。其他安装位置的独立版个人设置未被本轮复制或修改，用户实际升级前仍需备份对应目录。

使用：独立版停止全部 → 反馈设置 → 门槛 → 保存 → 新会话；DGHub 修改门槛 → 停用／重新启用 → 就绪后 F8。默认 75 保持原体验；30 更低血量才持续；0 不产生残血层。调门槛不会改变受伤脉冲基准或输出上限。
