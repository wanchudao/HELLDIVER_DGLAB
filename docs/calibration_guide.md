# 血条校准指南

> 适用: V0.3 源码版；也可明确指定 DGHub 插件的配置文件
> 前提: **HUD Scale 请保持 100%（游戏默认值）**

9 月 13 日完整主版本 EXE 已采用用户截图核验的 1080p 预设，无需先执行本文手动框选；见 [完整主版本使用说明](main_official_guide.md)。本文仍适用于经典源码入口和主动更换坐标的场景。

## 概述

示例坐标来自 1920×1080。首次使用、显示器/分辨率/HUD 缩放变化后都应核对并校准；21:9 等布局仍需现场验证。校准工具只截图和保存坐标，不连接设备。

根目录 `config.ini` 不存在时，程序只读 `config.example.ini` 作为模板；确认框选后才创建本地 `config.ini`。取消不会创建配置，也不会修改示例文件。

## 校准步骤

### 1. 打开游戏，进入地面任务

请在任务中的安全位置、满血或受伤但 HUD 清晰的状态下校准。**不要在飞船、菜单、加载或死亡画面校准：飞船上的经验条不是玩家血条。**

**确保 HUD Scale 为 100%**（设置 → HUD → HUD 缩放）。

### 2. 运行校准脚本

```bash
cd HELLDIVER_DGLAB
python tools/calibrate.py
```

工具读取目标配置的 `[capture] monitor_index`（1=主屏，2=副屏）。源码版默认写项目根目录；校准插件时必须明确指定它自己的配置：

```bash
python tools/calibrate.py --config dghub_plugin/config.ini
```

已有截图可跳过倒计时，用离线图片框选：

```bash
python tools/calibrate.py --image screenshots/full_health/20260621135510_1.jpg
```

截图必须与将要运行的分辨率和 HUD 布局一致。源码版与插件版配置不会自动同步；请核对终端打印的“目标配置”绝对路径。

### 3. 5 秒内切回游戏画面

终端显示 5 秒倒计时。**Alt+Tab 切回游戏**，确保目标显示器上的左下角血条可见。建议游戏使用无边框窗口，便于后续控制面板显示。

倒计时结束时会发出终端提示音并截图；截图失败会报错且不写配置。

### 4. 鼠标框选血条外框

截图完成后会弹出 OpenCV 窗口。**用鼠标拖拽框选血条整个外框**：

- ✅ 包含左端帽、中间血量条、右端帽
- ✅ 包含血条上下边框（上面到端帽上沿，下面到端帽下沿）
- ❌ **不要框到血条外的任何东西**（背景地形、武器图标、弹药 HUD 数字）

```
     ┌──────────────────────────────────┐ ← 框上沿（含端帽上端）
     │ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░ │
     │ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░ │ ← 框下沿（含端帽下端）
     └──────────────────────────────────┘
     ↑ 左端帽                          ↑ 右端帽
```

框选后按 **回车** 确认。如果框选位置异常（太窄/太宽），程序会提示并自动弹出重新框选的窗口。按 **ESC** 可随时取消。

### 5. 验证

先用 `start.bat` 启动强制 Mock 模式，进任务按 F8 或点击 `ARM FOR BATTLE`，检查满血读数约 95%-100%，受伤/回血方向正确，离开 HUD 时变为 unknown。此模式不启动 Node 后端，不连接设备。

`python tests/test_detector.py` 可评估仓库截图，但历史截图布局可能与当前校准不同，不能用它替代对当前游戏画面的核对。

如果偏差较大，重新校准同一目标配置。已有文件会先保存为 `config.ini.bak.日期_时间_微秒`，再原子写入新配置，避免同秒重复校准覆盖备份。

## 常见错误

| 错误 | 后果 | 正确做法 |
|------|------|----------|
| 死亡画面校准 | 血条不可见 | 请在满血或受伤状态下校准 |
| 飞船上校准 | 把经验条当成血条 | 进入地面任务后校准 |
| 框多了背景/地形 | 血量读数偏小 | 只框血条本体，框完仔细确认边界 |
| 框了弹药/武器 HUD | 血量检测被污染 | 血条在武器图标**左边**，不要框到武器区域 |
| 漏掉端帽 | 内框计算偏移 | 必须包含完整端帽结构 |
| 只框了红色血量段 | 程序无法推导端帽 | 框整个外框（含灰色/白色端帽） |
| HUD Scale 非 100% | 端帽比例可能不准 | 请恢复 HUD Scale 为 100% 后校准 |

## 技术说明

校准脚本通过 `cv2.selectROI` 获取用户框选的外框坐标，按 HD2 血条的固定几何比例自动推导内框和端帽忽略参数，写入 `config.ini`。

左右端帽沿用历史比例；内框高度按血条宽度换算（196 像素宽对应 7 像素有效高度），并在外框中居中，不再随端帽框选高度增厚。9 月 13 日三张满血截图已验证完整端帽框不会误读为零。不同布局、带鱼屏、HDR 和 HUD 缩放仍需另外验证。

保存时 `configparser` 会重新排版并移除注释；已有文件的原始内容保留在备份中，非 ROI 配置值（例如设备强度、通道）会保留。

## 恢复默认

先停止运行入口，再选择一个明确的备份文件恢复，不要用通配符拼接多个备份。请先另外保存当前配置，然后将所选备份复制为同目录的 `config.ini`。源码版和插件版分别选择对应目录中的备份。

要重新开始标定，可在停止程序后保存并移走旧本地配置，再运行校准工具；工具会从安全示例创建新配置。不要覆盖或删除自己的设备参数而不留备份。
