# HELLDIVER DGLAB 独立版 · 遥遥领先 UI · main-v1.0.0-beta.1

日期：2026-10-10。Windows x64 公开测试版，使用官方 DG-LAB SOCKET 后端，不依赖 DGHub。**本次不附 DGHub 插件包。**

## 下载与开始

下载 HELLDIVER_Main_Windows_x64_main-v1.0.0-beta.1.zip，完整解压后双击 HELLDIVER_Main.exe，保留 _internal。不要把 GitHub 自动生成的源码压缩包当成可运行软件。

Python、Node、图像库及主要运行库随包；不是“所有 Windows 系统绝对零依赖”。Windows N／删减版可能需要媒体组件；本次未完成干净系统矩阵测试。

选择同档位 HUD → 保存 → 截图检查或仅测试识别 → 选择电脑局域网地址 → 连接 APP 扫码 → 战场内 F8。结束时停止全部。只有配置／撤销连接权限才请求管理员确认，普通启动不修改防火墙。

## 功能

- 遥遥领先风格 UI：深蓝黑、青蓝、冷白、电路点阵和少量电弧；主窗口、设置、指南、截图、权限、控制窗及灵动岛统一风格。
- 待机动画可关闭；运行会话、截图／权限操作、最小化时停用，悬浮窗静态。
- 五种反馈：受伤、残血／濒死、治疗确认、持续舒缓、死亡；保留原事件规则和优先级。
- 残血门槛 0–100 整数百分比，默认 75；0 只关闭残血层，等于门槛不触发。
- 仅 A、仅 B、A+B，独立强度和上限，18 个内置波形。
- 1080p HUD 0.75–1.25，每档 +0.05，共 11 档；截图检查无需 APP 或后端。
- 无 HUD／暂停显示 HP --；单向状态快照超过一秒未更新显示中断、未知输出，不冒充设备读回。
- 反馈草稿离开／启动／退出时可保存、放弃或取消；F8 暂停不解锁设置。
