原生导入测试第一次被旧验收脚本的版本白名单拒绝，尚未进入插件启动；补入 1.0.7 后在新隔离目录完整重跑通过，原失败记录保留。

并行运行期间，最终独立版矩阵达到 60 秒硬超时两次，HUD 设置界面达到 45 秒一次，均记未完成。HUD 设置和主题界面已在原预算下单独重跑通过。第二轮 DGHub 两个 4K 长序列达到 45 秒总时长预算，原报告保留；将验收总预算与生产单帧期限区分后，用 90 秒有界进程重新执行这两项并通过，没有放宽任何输出断言。最终报告附原报告哈希及原失败摘要，已通过的 20 项绑定同一最终 EXE 复用，不把它写成全新一次运行。检查时游戏进程正在运行，系统 CPU 采样约 89%；没有据此修改游戏或系统设置，也不将其当成已证明的唯一原因。

一次开发环境 NumPy 导入曾打印原生异常诊断，但同一进程随后以 0 退出并完成全部回归；独立导入复核正常，原因未确认，不能写成已修复的程序缺陷。后续完整回归与冻结程序结果分别记录。
