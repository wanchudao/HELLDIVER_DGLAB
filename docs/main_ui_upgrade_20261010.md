# 遥遥领先 UI 独立版：测试、升级与回退

本包使用官方后端，不是 DGHub 插件。完整解压后直接运行 HELLDIVER_Main.exe；Python、Node、Pillow、OpenCV 等运行库已经随包，不需要自行安装，也不联网下载界面素材。不要只复制 EXE。

## 最快的测试方式

1. 先关闭旧版，避免两个程序抢用连接或重复输出。新包解压在独立目录，不会自动继承旧目录中的个人设置。
2. 打开新版，进入 HUD 设置，选择游戏相同的档位并保存。新 HUD 模式要求完整 1920×1080 原图和游戏画面。
3. 点击截图检查，选择原始截图。确认血条定位、血量和拒识原因；此步骤不启动后端，不连接 APP。单张图不测试事件。
4. 回到任务控制检查五种波形、A/B、血量门槛，保存后再连接。修改后离开页面、启动或退出会询问保存／放弃／取消。
5. 可先点仅测试识别，进入游戏后按 F8，检查有效血量和 NO HUD。反复折叠、展开灵动岛，移动鼠标及点击按钮，确认游戏未被切出。
6. 再选择手机同一局域网的电脑地址，点击连接 APP，扫码后进入战场按 F8。软件输出不等于 APP 或设备读回。点击停止全部结束本次会话。

待机电弧动画开关在主窗口右上角。启动会话后（即使 F8 暂停）装饰应保持静止；设置页、悬浮控制窗和灵动岛始终静止。日志从左下角展开。底部若显示状态更新中断，HP 和输出应显示未知，不能把它当作已确认的设备归零；查看日志并停止会话排查。

新版的手机 APP、游戏焦点及实体设备需要你实际复测。本包的自动验收是源码、最终软件及本机模拟 APP，不代替上述实际环境。

## 新目录连接失败

新目录中的后端路径也变了，因此旧目录的防火墙许可不一定适用。到使用指南顶部确认实际后端路径；检查电脑／手机网络、所选网卡及 Private 网络规则。若确实需要许可，进入连接权限，阅读范围后主动点击配置并确认管理员提示；可取消或撤销。软件不会默认放开权限，不要为测试关闭防火墙。

## 保留原后端路径的升级

1. 旧版停止全部并退出，确认没有本软件的残留会话。
2. 将整个旧安装目录复制到一个单独备份目录；保留完整旧 ZIP。记录旧版 _internal/runtime/node.exe 的绝对路径。
3. 保留原安装目录位置，将新包的 HELLDIVER_Main.exe 与完整 _internal 配套更新到同一位置。不要混用新 EXE 和旧运行库。
4. 原目录中的 feedback_settings.ini、hud_settings.ini、ui_settings.ini、sessions、日志及其他个人文件保留不覆盖。新包不带这些文件；不要通过删除整个原目录的方式升级。
5. 确认使用指南显示的后端绝对路径与升级前一致，再按前述流程复测。保持路径并不保证不同网络策略一定可连接；实际规则状态仍应检查。

本次未替你安装或覆盖旧软件，也没有修改现有防火墙规则。

## 回退

停止并退出新版，将新目录留作诊断备份，再恢复升级前整个安装目录及对应个人配置。不要仅替换 EXE。

回退到支持自定义门槛的上一版时可恢复原反馈配置；回退更早、不支持 [trigger] 的版本必须恢复升级前 feedback_settings.ini，旧版可能拒绝新增字段。ui_settings.ini 只影响本次新 UI，不混入反馈或 HUD 配置。

保留升级后 sessions 和日志作为诊断资料，不为回退删除历史记录。DGHub 配置／插件完全不涉及本次升级，不要导入这个独立版 ZIP。
