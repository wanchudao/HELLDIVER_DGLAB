# 独立主版本：遥遥领先风格 UI 验收记录

日期：2026-10-10。范围仅为官方 Node 后端独立版；不更新 DGHub 安装，不修改防火墙，不使用重置卡，不推送 GitHub。

## 本轮实现

- 深蓝黑、青蓝、冷白主题；外围电路、点阵及两个短电弧。没有新增雷霆、骷髅或徽章，不以整张预览图代替真实控件。
- 任务控制、反馈设置、HUD 设置、截图检查、使用指南、连接权限采用同一主题。保留 Windows 原生标题栏；主窗口目标客户区 1280×820，按所在显示器工作区收缩，内容不足时单列及滚动，底部停止入口独立保留。
- 主窗口反馈设置与独立设置窗口复用同一编辑组件和原校验／原子保存。离开编辑区、启动或退出时，未保存反馈修改可保存、放弃或取消；运行中及 F8 暂停时仍不可修改。
- 默认待机电弧只改变固定装饰的亮度，6 秒一周期，每个装饰最多 10 次／秒。会话、截图检查、权限操作、最小化及关闭时停用；设置页、完整控制窗、灵动岛始终静态。开关独立存入 ui_settings.ini，读取失败静态回退并提示。
- 工作进程通过单向、容量为一的非阻塞诊断队列上报当前会话状态，最多 5 次／秒；UI 不参与反馈决策。旧会话、倒序、损坏及过期数据不更新实时状态，超过一秒显示中断及未知输出。
- A/B 明确标注软件输出，不是 APP／实体设备读回；硬件发送模式记录最近成功提交值，无法确认时显示未知。无 HUD 和暂停时 HP 为 --。
- 完整控制窗、灵动岛仅由独立版显式选择新主题；共享绘制默认仍为旧主题，尺寸、按钮命中及不激活置顶机制未替换。
- 五类反馈、0–100% 门槛、11 档 HUD、官方配对和连接协议保持原规则。三个用户设置文件不混入历史会话。

## 动画、缩放与状态诊断

最终 EXE 实测会话期间两个装饰均停用，没有待机动画回调。短时对比显示关闭动画为零装饰更新、开启有低频更新；CPU 与采样时长列在 BUILD_INFO.json。这是短时观察，不是对所有电脑的性能保证。

100%、125%、150%、200% 使用 Tk 逻辑尺寸／字体模拟，并检查滚动与底部入口；工作区不足、任务栏空间、原生标题栏尺寸及负坐标另有几何测试。原生控制窗的本机实际 DPI 为 96。没有修改 Windows 缩放，也没有完成四种真实系统缩放、不同物理多显示器组合的人工验收；不得把逻辑模拟写成这些实机测试已通过。

状态序号、旧会话、损坏、过期、不可写文件及非阻塞限频通过源码测试；最终 EXE 注入诊断快照验证有效血量、无 HUD、过期显示，另由真实工作入口验证状态写入。注入快照只验证显示，不代表游戏或设备数据。UI 读写失败不能触发、停止或恢复反馈输出；安全停止仍由原工作进程负责。

## 发布与尚未验收事项

完整 ZIP 包含 EXE、运行库、官方后端、指南、升级／回退说明、界面截图和 BUILD_INFO.json。仅在新目录构建，不覆盖当前可用版本。包内不含个人 feedback_settings.ini、hud_settings.ini、ui_settings.ini、日志和 sessions。

同路径完整升级可保留已放行 node.exe 的绝对路径；在新目录运行不是同路径升级，旧防火墙规则不一定适用。软件不会默认申请系统权限。授权只由用户点击并明确确认发起。

本轮未进行新版真实手机 APP、实际游戏、实体设备、干净 Windows 虚拟机或不同物理 DPI／多显示器的全套验收；旧版用户成功记录不算本版通过。首版新 HUD 模式仍仅 1920×1080，不增加其他游戏分辨率支持。旧安装保留原兼容预设，未自动解释为 1.00。
