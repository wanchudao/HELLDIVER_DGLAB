# 死亡模式与极简直播按钮：开发验收记录

日期：2026-10-14。独立版 v1.0.0 Beta 2；DGHub 插件 1.0.6，插件 ID 保持 `helldiver_dglab`。

这是一轮新的本地测试包交付，不代表旧版手机／游戏结果自动适用于新版，也不是 GitHub 或插件市场已发布的记录。未覆盖当前安装、个人配置、日志或历史会话；未修改防火墙、宿主全局设置；未使用重置卡。

## 本轮实现

两版增加三种死亡模式，默认仍为定时反馈：

| 模式 | 连续有效正血到零后 | 复活后 | 手动结束 |
|---|---|---|---|
| 定时反馈 `pulse` | 按原规则，默认 5 秒 | 沿用原来的正血退出规则 | 暂停／结束会话 |
| 持续至复活 `until_revive` | 有效帧续发死亡层 | 重新确认有效正血后解除 | 暂停输出／结束会话 |
| 一次也不能死 `until_reset` | 记录本会话挑战已触发 | 不解除；其他事件强度继续叠加限幅 | 第一次 F8 重置且暂停，再次 F8 开始 |

鼠标暂停、保险关闭和异常暂停只停止输出，不清除挑战。HUD 无效立即停止输出，保留已确认的持续死亡标记；恢复首帧只重建基线，后续有效帧再决定续发／复活退出。首次零血不产生死亡，结束会话清除标记。持续层不通过无限定时器、重复死亡脉冲或 DGHub `permanent` 实现。

DGHub 新增 `panel_mode=live`。收起时只显示 32×32 逻辑像素按钮；点击只展开，拖动达到 4 逻辑像素取消点击；完整面板可收回，记住本次按钮位置。独立版保留原完整面板／灵动岛，没有直播按钮。两版均未改变 HUD 识别、伤害累计、治疗、强度设置及连接协议。

### 已观察到的宿主限制与首次启动超时

- 每次 `strength trigger` 会创建宿主事件卡片并提交音效通知；没有验证实际扬声器声音，不声称已静音。
- 无等待的同 ID 立即重启可能被旧适配器租约短暂归零；已验证正常注册后的 0.5 秒等待可排空本版本已知 0.30 秒租约，不保证排空其他长请求或卡死宿主。
- 本插件归零不取消原生长波形尾部任务。原生方法测试也观察到其他来源替换会取消旧尾部任务；不能据此保证所有交错波形都按界面描述无损播放。暂停本插件仅清自己的强度层、停止续发，不能保证设备缓存清空或整机强度为零。
- 第一轮隔离原生启动出现“10 秒未接入 WebSocket”超时，保留为未完成记录；第二轮在新的隔离目录、同一 EXE 和相同流程通过。没有证明首次超时原因，未通过改系统保护、宿主全局设置或放宽超时来伪造通过。请在自己的 DGHub 中复测首次导入／启用；若再次发生，保留宿主及插件日志，不消耗重置卡。
